# Лабораторная работа №4: Реализация REST API на Node.js (Express)

## Задание

Реализовать собственное REST API на Node.js с использованием фреймворка Express. API должно предоставлять 5 основных методов для работы с сущностью **Прогноз погоды (Weather)**:

- **GET /weather** — получение списка всех прогнозов с возможностью фильтрации
- **GET /weather/:id** — получение одного прогноза по ID
- **POST /weather** — создание нового прогноза
- **PATCH /weather/:id** — обновление существующего прогноза
- **DELETE /weather/:id** — удаление прогноза

Тестирование всех методов осуществляется через **Postman**.

---

## Сущность Weather (Прогноз погоды)

| Поле | Тип | Описание | Валидация |
|------|-----|----------|-----------|
| id | number | Уникальный идентификатор | Генерируется автоматически |
| city | string | Название города | Обязательное поле |
| date | string | Дата прогноза (ГГГГ-ММ-ДД) | Формат YYYY-MM-DD |
| temperature | number | Температура (°C) | Число |
| humidity | number | Влажность (%) | 0-100 |
| pressure | number | Атмосферное давление (гПа) | 800-1100 |
| description | string | Описание погоды | Обязательное поле |

---

## Фильтрация

Метод **GET /weather** поддерживает фильтрацию через query-параметры:

| Параметр | Описание | Пример |
|----------|----------|--------|
| city | Поиск по названию города (частичное совпадение, регистронезависимо) | `?city=Москва` |
| tempMin | Минимальная температура | `?tempMin=10` |
| tempMax | Максимальная температура | `?tempMax=20` |
| date | Точное совпадение по дате | `?date=2026-03-21` |
