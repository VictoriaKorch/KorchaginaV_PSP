# Лабораторная работа №3

## Задание

Цель работы — знакомство с экосистемой **Node.js** и менеджером пакетов **npm**. Необходимо реализовать веб-приложение, состоящее из двух страниц:

- **Страница списка** — отображение карточек с возможностью фильтрации.
- **Страница подробного просмотра** — детальная информация о выбранной карточке.

### Требования к функциональности

- Данные для карточек должны храниться в виде **mock-объектов** (коллекция в памяти).
- Реализовать **фильтрацию** карточек на странице списка.
- Добавить кнопку **«Добавить»** — при нажатии копируется первая карточка из списка.
- Добавить для каждой карточки кнопку **«Удалить»**.

### Технологии

- **Node.js** — серверная среда выполнения JavaScript.
- **npm** — управление зависимостями.
- **HTML / CSS / JavaScript** — клиентская часть.
- **Express** (рекомендуется) — для организации сервера и маршрутизации.
