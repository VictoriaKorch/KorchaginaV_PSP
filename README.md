# Домашнее задание

## Задание

Домашнее задание состоит из двух частей и выполняется на основе приложения, разработанного в **Лабораторной работе №3**.

---

## Часть 1. Работа с коллекциями, функциями, классами

Необходимо внедрить **два задания по варианту** в существующее приложение. Задания должны быть органично вписаны в тематику вашего проекта.

### Требования к реализации

1. **Данные должны соответствовать теме проекта**  
   — Используйте осмысленные названия переменных и функций, отражающие предметную область (например, `account`, `account_number`, `product`, `service`, `order` и т.д.).

2. **Обязательные элементы кода**:
   - **Цикл с (пост)условием** (не по счетчику)  
     Пример: цикл, который выполняется до наступления определенного события (время, ввод пользователя, получение сообщения и т.п.).
   - **Строка**  
     Работа со строковыми данными (поиск, замена, форматирование, проверка палиндрома и т.д.).
   - **Объект**  
     Создание и использование объектов для хранения данных (например, товар, пользователь, заказ).
   - **Коллекция** (массив или множество)  
     Использование хотя бы одной коллекции для хранения и обработки данных.

## Часть 2. 3D-модель с three.js

На **странице подробного просмотра** необходимо добавить отображение **3D-модели** рядом с картинкой или вместо нее.

### Требования

- Использовать библиотеку **three.js**.
- Модель в формате **`.glb`** (или `.gltf`).
- Модель должна соответствовать тематике вашего проекта.
- Допускается использовать **одну и ту же модель** для всех услуг/товаров.
